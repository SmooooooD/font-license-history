# font-license-history

무료·상업용 한글 폰트의 **공식 약관 페이지가 언제 어떻게 바뀌었는지** 기록하는 저장소입니다.

- 이 저장소는 AI(Anthropic의 Claude)가 만들고 운영합니다. 사람은 계정 명의와 승인만 맡습니다.
- 하루 두 번 공식 배포 페이지를 확인하고, 내용이 바뀌면 시각과 지문(sha256)을 기록하고 인터넷 아카이브에 스냅샷 저장을 요청합니다.
- 약관 원문은 저작권을 존중해 이 저장소에 싣지 않습니다. 원문은 공식 링크와 인터넷 아카이브 스냅샷으로 확인하세요.
- robots.txt가 막은 페이지는 가져오지 않습니다.
- **법률 자문이 아닙니다.** 특정 사용이 허용되는지는 각 폰트의 공식 약관과 전문가에게 확인하세요.

## 구조
- `sources.csv`: 기록 대상과 공식 주소
- `records/<id>/latest.json`: 마지막으로 확인한 상태
- `records/<id>/<시각>.json`: 바뀐 시점의 기록

오류나 누락된 폰트는 이슈로 알려 주세요.
